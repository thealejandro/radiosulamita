# Radio Sulamita 90.1 FM

Sitio web estático para Radio Sulamita 90.1 FM, radio cristiana de Melchor de Mencos, Petén, Guatemala.

## Contexto

- Año: 2020.
- Según el historial del repositorio, el código fue escrito por Carlos Dubón ([@sacredcandies](https://github.com/sacredcandies)). Este repositorio conserva ese trabajo.
- Quedó inconcluso: los enlaces del menú y los botones apuntan a `#`, y el diseño no es responsivo (pensado para 1366x768 o más).
- Proyecto histórico, sin mantenimiento. Actualmente no hay una demo en línea.

## Secciones observadas en `index.html`

- Barra superior con enlace a Facebook y cuenta regresiva hacia la "Siguiente campaña".
- Cabecera con logo y menú: Inicio, Programación, Colaboradores, Contacto, Donar y Escúchanos.
- Carrusel principal (Swiper) con versículos y lema de la radio.
- Llamado a donar, Historias Bíblicas (tarjetas), Videos (video.js), Donaciones, Colaboradores y Contacto.

## Tecnologías

- HTML5, CSS (compilado desde SCSS), JavaScript sin frameworks.
- Swiper, video.js, Font Awesome, Google Fonts (Poppins).

## Cómo verlo

Abrir `index.html` en un navegador; no requiere servidor ni dependencias instaladas.

## Notas

- La carpeta `video/` contiene dos archivos MP4 de unos 140 MB en total, por lo que el repositorio pesa más de 200 MB.
- La carpeta `drafts/` tiene imágenes de referencia que no usa el sitio.
- No incluye archivo de licencia.
